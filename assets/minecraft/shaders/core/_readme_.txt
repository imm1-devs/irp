Most of the overriden shaders make items emissive or discard unwanted fragments (vertexes) rendering.

particle - makes some of the particles emissive
rendertype_entity_cutout - renders block items in inventories or hand/head, ignited entities overlay
rendertype_entity_translucent - renders entity parts
rendertype_glint_direct - discards enchanted items glint
rendertype_gui_overlay - discards item selection overlay in inventories
rendertype_lines - renders the block selection
rendertype_text - removes the text shadows in titles
rendertype_text_see_through - discards the tag name background

Full information on the Minecraft core shaders can be found here:
